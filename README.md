# road

도로 기상 이동관측(노면온도) 결과를 보여주는 정적 웹 화면입니다.

- `index.html` — 회의용 한 장 브리핑 화면 (사이트 첫 화면)
- `analysis.html` — 상세 분석 화면 (브리핑의 '상세 분석 화면 →'로 이동, 지도 · 연간 분석 · 관측일별 위험구간 위치)
- `meeting.html` — 예전 주소용, 첫 화면으로 넘겨줌

## 휴대폰에 앱처럼 설치하기

사이트(https://sukjashin.github.io/road/)는 웹 앱(PWA)이라 홈 화면에 아이콘으로 설치해 앱처럼 쓸 수 있습니다.

- 안드로이드(크롬): 사이트를 열고 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- 아이폰(사파리): 사이트를 열고 공유 버튼 → **홈 화면에 추가**

한 번 열어 본 화면·관측자료는 휴대폰에 저장되어 인터넷이 약해도 열립니다(지도 배경은 인터넷 필요).
인터넷이 되면 항상 최신 자료를 먼저 받아오므로 따로 업데이트할 필요는 없습니다.
관련 파일: `manifest.webmanifest`(앱 이름·아이콘), `sw.js`(저장 규칙), `icons/`.

## 새 관측 자료 넣기

상세 화면 메뉴는 **관측 연도 → (그해 관측 자료가 여럿이면) 관측 자료** 2단계이며, 자료에서 자동으로 만들어집니다.
연도를 고르면 그해 모든 주행을 합친 **연간 분석**(평균 노면온도·평균 기온·위험·주의 비율)과 **연도별 비교표**가 나옵니다.

### 계속 쓸 자료 (상세·회의용 화면 모두, 모든 사람에게 보임)

1. `aws_1분/<이름>/` 폴더에 관측파일(`.txt` `.csv` `.xlsx`)을 넣습니다. 하위 폴더까지 모두 읽습니다.
   - 연도별로 쓰려면 `aws_1분/2023/`, `aws_1분/2024/` … 처럼 연도 폴더에 넣으면 됩니다.
   - 노선별로 쓰고 싶으면 `aws_1분/27번국도(곡성~고흥)/`처럼 노선 이름 폴더도 됩니다. 연도는 파일 날짜로 자동 구분됩니다.
   - 자동으로 건너뛰는 파일: 같은 날 `_aws_` 파일이 있는 `_real_` 파일(같은 주행의 초 단위 원시자료),
     다른 파일과 시각이 모두 겹치는 파일(누적 덤프), 위치·노면온도가 없는 고정 관측소 파일.
   - 15분 넘게 끊긴 곳에서 주행을 나눕니다(일출전/일출후 등).
2. 다음을 실행합니다.

   ```bash
   node build-observations.cjs
   ```

   폴더에 읽을 수 있는 파일이 있는 이름은 내장자료가 **폴더 내용으로 통째로 교체**되고, 건너뛴 파일과 이유가 출력됩니다.
   두 화면이 새 자료를 바로 읽도록 버전 값도 갱신됩니다.
3. 바뀐 파일(`road-observations.js`, `index.html`, `analysis.html`)을 커밋·업로드합니다.

그 밖의 명령:

```bash
node build-observations.cjs --list
```

```bash
node build-observations.cjs --remove "2023"
```

### 읽을 수 있는 파일 형식

- AWS 1분 관측파일: `#Time,Site,기온(℃),…` 머리글, 위·경도가 정수/소수 칸으로 나뉜 형식 (txt·csv, UTF-8 또는 EUC-KR)
- 열 이름 머리글 csv·xlsx: 시각·노면온도·위도·경도 열이 있으면 됩니다. 예: `wdate_,temp_,r_temp_,humi_,alti_,longi_,lati_`
  - 최신 행이 위에 있어도 시간순으로 정렬하고, 1초에 여러 건인 자료는 10초에 1건으로 줄여 반영합니다.
  - 알아보는 열 이름: 시각 `wdate_`/`time`/`일시`, 노면온도 `r_temp_`/`노면온도`, 기온 `temp_`/`기온`, 위도 `lati_`/`lat`/`위도`, 경도 `longi_`/`lon`/`경도`

### 잠깐 확인만 할 자료 (상세 화면, 내 브라우저에서만)

상세 화면의 **+ 관측 자료 추가** → 파일 또는 폴더 추가 → **관측 자료 이름** 확인 → **실행**.
위와 같은 규칙으로 읽어, 해당 연도 메뉴에 '추가' 표시와 함께 나타납니다. 새로고침하면 사라지고 회의용 화면에는 나오지 않습니다.
