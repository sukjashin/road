# road

도로 기상 이동관측(노면온도) 결과를 보여주는 정적 웹 화면입니다.

- `index.html` — 상세 분석 화면 (지도 · 관측일별 위험구간 위치 · 관측 요약)
- `meeting.html` — 회의용 한 장 브리핑 화면

## 새 관측 자료 넣기

'관측 대상 선택' 메뉴는 미리 정해져 있지 않고, 자료에 적힌 **관측 대상 이름**별로 자동으로 만들어집니다.

### 계속 쓸 자료 (상세·회의용 화면 모두, 모든 사람에게 보임)

1. `aws_1분/<관측 대상 이름>/` 폴더를 만들고 관측파일(`.csv` 또는 `.txt`)을 넣습니다.
   - 폴더 이름이 그대로 메뉴 이름이 됩니다. 예: `27번국도(곡성~고흥) 2026`
   - 이름을 `노선(시작지명~끝지명)` 형식으로 쓰면 관측일별 위험구간 위치 차트 양 끝에 지명이 표시됩니다.
   - 같은 노선이라도 연도별로 따로 보고 싶으면 이름에 연도를 붙이세요. 같은 이름끼리는 한 메뉴로 합쳐집니다.
2. 다음을 실행합니다.

   ```bash
   node build-observations.cjs
   ```

   `road-observations.js`에 자료가 추가되고, 두 화면이 새 자료를 바로 읽도록 버전 값도 갱신됩니다.
   이미 들어 있는 자료는 그대로 유지되며, 같은 관측 대상·같은 파일명이면 새 파일로 교체됩니다.
3. 바뀐 파일(`road-observations.js`, `index.html`, `meeting.html`)을 커밋·업로드합니다.

그 밖의 명령:

```bash
node build-observations.cjs --list
```

```bash
node build-observations.cjs --remove "27번국도(곡성~고흥) 2026"
```

### 잠깐 확인만 할 자료 (상세 화면, 내 브라우저에서만)

상세 화면의 **+ 관측 자료 추가** → 파일 또는 폴더 추가 → **관측 대상 이름** 입력 → **실행**.
같은 이름끼리 묶여 메뉴에 '추가' 표시와 함께 나타납니다. 새로고침하면 사라지고 회의용 화면에는 나오지 않습니다.
