## 추진개요

기존에 앱인벤터로 제작한 안드로이드용 주소찾기의 이용 불편을 개선하기 위해, 웹브라우저에서 이용할 수 있는 출장지원시스템으로 발전시켰다.
관측지점 검색·위치 확인·방문 경로 검토와 함께 관측차량의 주차 장소 선정 지원 도구를 마련하여, 목적지 탐색부터 현장 접근 준비까지 지원 범위를 확대하였다.
GitHub Pages를 통해 웹주소로 접근할 수 있도록 운영하고 있으며, 개발 과정에서의 AI 활용 내용은 [실제 활용 도구와 코드 작성·오류 수정·화면 개선 등 수행 내용을 확인하여 기재]한다.

## 프롬프트

**아래는 제출용 정리 예시이며 실제 대화 원문이 아니다. 실제 요청 내용과 일치하는 문장만 남기거나 실제 기록으로 교체한다.**

- “앱인벤터로 만든 안드로이드용 주소찾기를 웹브라우저에서 이용할 수 있도록 바꾸고, 관측지점을 이름·주소·장비번호로 검색해 지도에서 확인하도록 구성해줘.”
- “출장 대상 장비를 여러 곳 선택하면 사무실 출발·복귀 기준으로 방문 순서와 이동거리·시간을 계산하고 지도앱 길안내로 연결해줘. 추정값은 추정이라고 표시해줘.”
- “관측차량 출장 시 주차 장소를 찾는 불편을 줄이도록, 출장 전에 장소 선정을 지원하는 웹페이지를 만들어줘.”

## 활용결과

### 1. 앱 기반 주소찾기를 웹 기반 출장지원시스템으로 개선

기존 안드로이드용 주소찾기를 웹으로 전환하여, 별도 앱 설치 없이 웹주소로 접근할 수 있는 구조를 마련하였다. 직원 간 링크 공유를 통해 활용할 수 있도록 GitHub Pages에 게시하였다.

### 2. 관측지점 검색에서 방문 계획까지 연결

공개된 지상 관측자료 100개 항목을 바탕으로 지점명·주소·관측장비번호 검색과 지도 위치 확인 기능을 구성하였다. 출장 대상 장비를 최대 8곳까지 선택하여 사무실 출발·복귀 기준의 방문 순서와 이동거리·시간을 계산하고, 지도앱 길안내로 연결하도록 구현하였다.

도로 경로 정보를 이용할 수 없는 경우에는 직선거리와 설정 속도에 따른 추정값임을 표시하며, 실시간 교통 상황은 반영하지 않는다. 관측지점 자료는 CSV로 관리하고, 사진이 등록된 지점은 현장 파노라마 연결을 통해 설치 위치와 주변 환경을 살펴볼 수 있도록 구성하였다.

### 3. 주차 장소 검토까지 출장 준비 범위 확대

관측차량 출장에서는 목적지를 찾는 것뿐 아니라 도착 후 차량을 세울 장소를 찾는 불편도 있었다. 이를 개선하기 위해 주차 장소 선정을 지원하는 웹페이지를 추가 제작하였다. 관측지점 검색·방문 경로 확인과 함께 활용하여, 출장 전에 목적지와 이동 경로, 차량을 세울 장소를 함께 검토하도록 하였다.

이를 통해 **‘관측지점 검색 → 방문 경로 검토 → 주차 장소 검토 → 현장 방문’**으로 이어지는 출장 준비 과정을 지원하는 웹 도구를 마련하였다.

### 최종 결과물

- 관측지점 검색·출장 경로 지원: https://sukjashin.github.io/weather-station-map/
- 관측차량 주차 장소 선정 지원: https://sukjashin.github.io/weather-station-map/observation_support_site/index.html

두 웹페이지를 하나의 출장지원 업무 사례로 설명하며, 단일 화면이나 자동 데이터 연동을 구현했다는 의미는 아니다.

## 기대효과

| 평가항목 | 기대효과 |
|---|---|
| 효율성 | 관측지점 검색·방문 경로·주차 장소를 사전에 검토하여 출장 준비의 반복 작업과 현장 도착 후 장소 탐색 부담을 줄이는 데 기여할 것으로 기대한다. |
| 확산성 | 웹주소 공유로 다른 직원의 접근을 돕고, 지역별 관측자료와 출발지 설정을 변경하여 유사한 장비 점검·현장조사 업무에 적용할 수 있다. |
| 창의성 | 직접 제작한 주소찾기를 출발점으로, 실제 출장 과정에서 겪는 이동 경로와 주차 장소 문제까지 개선 대상으로 확장하였다. |
| 완성도 | 검색·지도 위치 확인·방문 순서 계산·길안내·현장정보 확인 기능과 주차 장소 선정 지원 도구를 마련하여 출장 준비의 여러 단계를 지원한다. |

업무시간·이동거리·예산 절감 효과는 실측값이 확인되지 않아 정량 성과로 제시하지 않았다. 향후 동일 출장 조건에서 기존 방식과 시스템 활용 방식의 준비시간 및 주차 장소 탐색시간을 비교하여 효과를 확인할 수 있다.

## 제출 전 확인 메모 — 최종 제출본에서 삭제

- 공고 양식에 옮겨 설명서 2쪽 이내로 편집하고, 결과물 화면은 별첨한다. 이 파일은 통합 내용 초안이며 2쪽 편집을 완료한 문서가 아니다.
- 소속·직급·성명, 용역·예보기술 연계 여부, 실제 사용 AI와 활용 작업을 확인한다. 예시 프롬프트를 실제 요청 기록과 대조한다.
- 관측자료 100개 항목과 최대 8곳 선택은 공개 CSV·코드에서 확인했다. 모든 기능의 실제 브라우저 동작을 검증한 것은 아니다.
- 주차 장소 선정 기능은 제작자의 설명을 근거로 작성했다. 추가 사이트는 접속 지연으로 상세 기능을 확인하지 못했으므로 자동 추천, 실시간 주차 가능 여부, 주차 적법성·안전성 보장 등의 주장은 포함하지 않았다.
- 주차 지원 화면과 실제 활용 사례를 확보하고, 절감 수치는 측정한 경우에만 추가한다.
